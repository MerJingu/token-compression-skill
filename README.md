# 以压缩上下文和精简对话实现的 token 压缩 skill

**Token Compression Skill (TCS)** — cutting token cost by compressing context reads and streamlining replies.

一套行为级 token 经济技能：从「读」和「写」两侧同时削减 token 消耗。不修改 tokenizer 或上下文窗口，收益来自少读、精准读、写得短。

## 工作原理

- 输入侧（读）：先定位再读（rg）、窗口读取、增量重读、长文摘要；摘要视为权威，不再复读原文。
- 输出侧（写）：结论先行，去掉语气词、冗余、问题复述与过程叙述，按最省 token 原则选格式。
- 测量：[scripts/estimate_tokens.py](scripts/estimate_tokens.py)，启发式估算（CJK 1 字≈1 token，其余 4 字符≈1 token），用于前后相对比较。

## 安装与使用

复制整个目录到 `$CODEX_HOME/skills/token-compression`（Windows 默认 `C:\Users\<用户名>\.codex\skills`），然后：

- 对话中显式调用：`$token-compression`
- 或遇到长上下文、省 token / 精简类请求时自动匹配（默认允许隐式触发）。

| 测试 | 未使用 | 使用 | 节省 |

## 局限性（务必阅读）

1. **可能提高幻觉率**：摘要与过滤会丢弃细节，信息不足时模型更容易自行补全出错误内容；摘要一旦出错还会被当作权威放大。关键事实、数字、代码请保留原文校验。
2. **只是行为级压缩**：不改变 tokenizer、上下文窗口或计费方式，省的是读取与输出行为。
3. **固定字数/格式任务收益有限**：硬性字数要求占大头，只能去掉冗余（实测 400 字文章仅省 14.6%）。
4. **不适合的场景**：需要完整原文、精确引用、法律/安全/合规审查、详尽教学讲解，或依赖长上下文深层推理的任务。
5. **测量是启发式**：估算 token ≠ API 实际计费；精确值需用 tiktoken 按目标模型 tokenizer 复测。
6. **输入侧依赖搜索命中质量**：过滤过窄会漏读关键信息，过宽则省不了多少。
7. **技能自身有加载成本**：短对话中加载整套技能可能不划算，长上下文才是净收益。
8. **语气词黑名单固定**：可能误删携带真实语气的表达，不适合需要礼貌或安抚语气的沟通场景。
